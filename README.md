# Hateful-Meme-Detection
AI-based hateful meme detection using Python and machine learning

## Project Overview
This project focuses on detecting hateful memes using Artificial Intelligence and Machine Learning techniques. It analyzes text extracted from images to identify and classify potentially hateful content.
## Technologies Used
- Python
- Machine Learning
- OCR (Optical Character Recognition)
- TF-IDF
- Random Forest
- Tkinter
- MySQL

## Features
- User login page
- Meme text extraction using OCR
- Text preprocessing and feature extraction
- Hateful meme classification using Random Forest
- Graphical user interface using Tkinter
- Database connectivity using MySQL

## Project Files
- `main.py` – Main application
- `admin.py` – Admin login functionality
- `dataupload.py` – Data upload functionality
- `dataupload1.py` – Additional data upload functionality
- `hate_meme.sql` – SQL database script
- `Hatememe_dataset.csv` – Dataset

## How to Run
1. Install the required Python libraries.
2. Set up the MySQL database using `hate_meme.sql`.
3. Configure the database connection.
4. Run `main.py` to start the application.
